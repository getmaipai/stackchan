# Support

Most problems are fixed on the [Troubleshooting](docs/user/troubleshooting.md) page. Read it first.

## Where to ask

- A question: read the [questions page](docs/user/faq.md). If your answer is not there, open an issue.
- Something broken: open an issue with the bug report form.
- An idea: open an issue with the feature request form.
- A security problem: do not post details in public. Follow [SECURITY.md](SECURITY.md).

## What to include

1. The output of `stackchan check`, run on the host computer.
2. The version. On the robot, tap **More**, then **Version**.
3. Your language, as set on the settings page.
4. What you did, what you expected and what happened.

Never paste a token, a Wi-Fi password or the pairing code. Remove them before you post.

This is an independent project run by its owner. There is no promised reply time.
