# Release notes

## 1.0.0

The first release of MaiPai for StackChan. Everything on the [Features](features.md) page is in this release unless it is marked Needs MaiPai Home.

- Private by design: the robot talks only to your host or your MaiPai Home hub.
- Voice with a wake word, follow-up questions, interrupting and a persona text.
- Faces, a clock face, night mode and captions.
- Timers and alarms, named timers, reactions, a mood that grows with care, an hourly chime and a low-battery ladder.
- Camera features, off until you turn them on.
- Mute, camera off and full quiet by tapping the face.
- A trimmed robot build: Bluetooth off, no host-controlled installs, no keys in images, and a Wi-Fi setup page with an on-screen code in English and Spanish.
- Eight face styles, nine face extras, word reactions, a time zone picker, a network test and a version screen.
- Six languages: English, Spanish, French, German, Portuguese and Italian.
- Offline phrases, dance on request, six named dances and a sway to music.
- Travel: the robot joins your private network by itself when it cannot reach your host.
- Reset on the robot, and a restart guard.
- Several robots on one host, speech speed and pitch, and a cooking persona.
- Signed updates over Wi-Fi with rollback.

### Built, not yet checked on a robot

Sound, screen looks, head petting, the setup page, the reset screen and a signed update with a real key.

### Known gaps

- No phone app, no online app downloads, no support for the factory ESP-NOW remote.
- The link on a home network is plain until the encrypted link ships. Use a network you trust.
- Measured speed numbers for named computers and models are still to come.

### Hardware

MaiPai for StackChan targets the StackChan robot with the CoreS3 controller. If M5Stack changes a part, we note it here with the date and any change you need to make.

## Earlier versions
