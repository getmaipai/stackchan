# Which setup is right for me?

The robot is the same hardware in all three. Pick the one that fits.

## Factory firmware

Use it when:

- You find the default features, privacy and performance acceptable.
- You rely on the phone app, live video, remote avatar control, the ESP-NOW remote or the app center.
- You have no hardware to host a model, and you do not want to set any up.

See [Compare](compare.md).

## MaiPai for StackChan

Use it when:

- You want your conversations to stay in your home, and better privacy than you have now.
- You want it faster and more capable: timers, reactions, games, mute and camera-off switches.
- You want optional local packages, such as the coding companion.
- You have, or will set up, a small always-on computer such as a Raspberry Pi 5 for the host. It can install and run a small model itself, or you can point it at a bigger model on another computer.
- You are happy with a simple, focused voice robot.

Start with [Getting started](getting-started.md).

## MaiPai for StackChan with MaiPai Home

Use it when:

- You have the same needs as MaiPai for StackChan, a private voice robot that runs on your own LLM, and you want more.
- You want extras for the robot, such as:
  - Names for the people the camera sees, and "what is this".
  - <span class="planned-tag">Planned</span> Shared room alerts are coming with MaiPai Home.
  - Photos, face follow and remote control can run on your own host with no Home. Room watch is coming. See [Find the robot and control it remotely](find-and-remote.md).
- You want extras across all of MaiPai Home: face and voice recognition, memories, content filtering, companions and personalities, custom and cloned voices, calendars and household rules.

Start with [Use MaiPai Home as the brain](with-maipai-home.md).

## Change your mind later

Moving between the last two is one choice on the [Brain page](choose-a-brain.md), and the robot is not reflashed. To move to or from the factory firmware, see [Switch from the factory firmware, or go back](switch-from-the-factory-firmware.md).

## Still need help?

Run `stackchan check`, then read [Troubleshooting](troubleshooting.md). If that does not fix it, open an issue on the Issues tab and tell us what you saw.

For a full side-by-side, see [What you get with your own model and with MaiPai Home](local-vs-home.md).
