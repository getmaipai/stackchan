# Which setup is right for me?

The robot is the same hardware in all three.

| Choice | Use it when |
|---|---|
| **[Factory firmware](compare.md)** | You rely on the phone app, live video, remote avatar control, the ESP-NOW remote or the app centre. |
| **[MaiPai for StackChan](getting-started.md)** | You want a simple, private voice robot that runs on your own LLM. |
| **[MaiPai for StackChan with MaiPai Home](with-maipai-home.md)** | You also want the camera, watching, a baby or pet monitor, find and remote control, games, a coding companion, memory and calendars. |

You can change your mind later. Moving between the last two is one setting, `brain = "llm"` or `brain = "home"`, and the robot is not reflashed. To move to or from the factory firmware, see [Switch from the factory firmware, or go back](switch-from-the-factory-firmware.md).

## Still need help?

Run `stackchan check`, then read [Troubleshooting](troubleshooting.md). If that does not fix it, open an issue on the Issues tab and tell us what you saw.
