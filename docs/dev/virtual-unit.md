# Virtual unit


> Part of the [playground docs](../playground/index.md). This page is the full reference; the playground pages are the guide.

A headless StackChan on this Mac: the unit's own LVGL drawing code behind the same tool protocol the host speaks, with a fake clock, scripted touch, and golden frames. Development only; no firmware build.

## Build (once per firmware change)

Needs `clang` and a built firmware tree: `MAIPAI_FW_TREE_ROOT` when it is set, otherwise main's reference tree `~/esp/stackchan-rebuild/main-ref`, made by `bash scripts/fw-ref-tree.sh`. `scripts/ref-tree.py` picks it and says plainly when it is missing or older than `firmware/patches/ORDER`; no other tree is chosen for you. The goldens in `host/tests/golden` are made against that tree, and `host/tests/golden/golden-order.sha1` holds the hash of the `ORDER` they were made for: `scripts/check.sh` fails when `ORDER` changed and the goldens were not regenerated in the same landing (`scripts/golden-stamp.py`).

1. `bash scripts/virtual-unit/build-face.sh` makes the overlay tree (the tree plus the UX patches listed in the script) and the face renderer.
2. `bash scripts/virtual-unit/build-screens.sh` builds the screens, lock and cover renderers from it.

## Use

- `python3 scripts/virtual-unit/view.py 8780`, then open `http://127.0.0.1:8780/`: 3D head, tap and swipe, call any tool, scenarios.
- `python3 scripts/virtual-unit/scenarios.py [--update]`: golden frames and layout checks (`host/tests/golden`). `--update` only after looking at the new frames.
- `python3 scripts/virtual-unit/face_consistency.py`: five styles by every emotion.
- `python3 scripts/virtual-unit/bench_checks.py --report`: the bench check dry runs.
- `schema/tools.json` is generated by `scripts/virtual-unit/tools_extract.py` from `firmware/patches` in ORDER.

## Tests

`bash scripts/test-all.sh` builds the renderers when a firmware tree is present, then runs the whole host suite in 4 processes; `bash scripts/test-fast.sh` leaves out the slow tests (docs/dev/test-speed.md). Without a tree the virtual unit tests skip with one message. After a patch changes a core, run `uv run --project host python scripts/regen-core-tables.py` so the page tables match.

## Clock wrap soak (24.9 and 49.7 days)

- `host/tests/firmware/wrap_soak_test.c` (run by `tests/test_stackchan_wrap_soak.py`): the same script of events for every core that uses the stamp helper (time, lock, pickup, games input, status, fx, face tracking, remote), run from start times on the 2^31 ms and 2^32 ms points, and from 1000 ms. The answers must be identical. A second part reads armed deadlines again after 2^31 ms and 2^32 ms of silence: none may read pending.
- `host/tests/test_face_wrap_soak.py`: the face renderer with the fake clock set by its `clock <ms>` command. Both eyes and the mouth must stay drawn (within 12 percent of the reference run) before, across and after both points. Needs the built renderer. `build-face.sh` now applies SF01, because the older base tree still drew the right eye shut for good once the clock passed 2^31 ms.

The browser view has a real-proportion 3D body with power, cable, Wi-Fi, battery and servo axes: see `virtual-unit-3d.md`.
