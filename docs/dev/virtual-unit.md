# Virtual unit

A headless StackChan on this Mac: the unit's own LVGL drawing code behind the same tool protocol the host speaks, with a fake clock, scripted touch, and golden frames. Development only; no firmware build.

## Build (once per firmware change)

Needs `clang` and a built firmware tree (default `~/esp/stackchan-rebase/final15`, or `MAIPAI_FW_TREE_ROOT`).

1. `bash scripts/virtual-unit/build-face.sh` makes the overlay tree (the tree plus the UX patches listed in the script) and the face renderer.
2. `bash scripts/virtual-unit/build-screens.sh` builds the screens, lock and cover renderers from it.

## Use

- `python3 scripts/virtual-unit/view.py 8780`, then open `http://127.0.0.1:8780/`: 3D head, tap and swipe, call any tool, scenarios.
- `python3 scripts/virtual-unit/scenarios.py [--update]`: golden frames and layout checks (`host/tests/golden`). `--update` only after looking at the new frames.
- `python3 scripts/virtual-unit/face_consistency.py`: five styles by every emotion.
- `python3 scripts/virtual-unit/bench_checks.py --report`: the bench check dry runs.
- `schema/tools.json` is generated by `scripts/virtual-unit/tools_extract.py` from `firmware/patches` in ORDER.

## Tests

`bash scripts/test-all.sh` builds the renderers when a firmware tree is present, then runs the whole host suite. Without a tree the virtual unit tests skip with one message. After a patch changes a core, run `uv run --project host python scripts/regen-core-tables.py` so the page tables match.
