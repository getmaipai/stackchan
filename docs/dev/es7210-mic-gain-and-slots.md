# ES7210 microphone gain and TDM slots on the CoreS3 (measured 2026-11-18)

Read from `firmware/managed_components/espressif__esp_codec_dev/device/es7210/es7210.c` and measured with `self.bench.mic3_check` on the unit.

**Slots.** The codec runs in TDM mode (register 0x12 = 0x02) and the I2S receiver reads four slots. The slot order is not the microphone number order. Measured: slot 0 is MIC1 (a real microphone), slot 1 is the speaker loopback (its level follows the speaker volume: about 2 at volume 0, 880 at 40, 3,100 at 70, and it follows the MIC3 gain), slot 2 follows the volume acoustically and ignores the MIC3 gain (a real microphone), slot 3 is silent. The base firmware's echo reference channel is slot 1 for the same reason. A release image reads slot 1; only a bench build can read another slot.

**Gain.** `esp_codec_dev_set_in_channel_gain` converts decibels to the register value in steps of 3 dB from 0 dB (index = floor((dB + 0.5) / 3) up to 30 dB, then 34.5, 36 and 37.5 dB). The MIC3 gain register is set per channel (mask bit 2 is MIC3). Measured on the loopback: the level rises in 3 dB steps from 3 to 12 dB, falls by about 7.6 dB at 15 dB and rises again, which the register mapping alone does not explain (a hardware effect of the analog stage, or a measurement across a changed operating point). Use 12 dB (`CONFIG_MAIPAI_MIC3_GAIN_DB`, the default): the level is in the linear part and the peak stays far below full scale at the highest speaker volume.

**Decision for the echo reference (2026-11-18).** The AEC reference gain stays at 12 dB. The registers map as the code says (gain index in bits 3..0, 3 dB steps, the channel's enable bit 4 set once at start), so the 15 dB dip is not a software effect; the likely cause is the codec's own level control or the analog stage reacting to the loopback level, and a sweep of 9 to 21 dB with `self.bench.mic3_check` (slot 1, volume 40 and 70) would show which. It does not affect the choice: bench window 10 measured an echo return loss of 66.6 dB median at volumes 35 and 60 and 63.9 dB at the volume cap (the target was 15 dB) with 12 dB. Do not raise the gain above 12 dB without that sweep.
