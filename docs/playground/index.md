# MaiPai for StackChan: the playground

The playground is a virtual StackChan. It draws the robot's real screens, moves a 3D body, runs its dances and games, and answers the same tool calls the real robot answers. You need no robot to use it. It is a simulation: nothing you do here touches a real robot unless you pick Live mode.
