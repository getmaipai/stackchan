# Languages

The robot's screens speak English and Spanish. The first-run screens also speak French, German, Portuguese and Italian. Those four are machine drafts that a native speaker has not read yet. The robot's legal notice on its version page is English only until it is reviewed. More languages are planned in tiers: Latin-script languages first, then Chinese, Japanese and Korean through font packs, then right-to-left scripts.
