# Keyboard and mouse cheat sheet

Everything you can do with the mouse, the keyboard and a finger on the playground window.

## On the 3D robot

| Do this | It does this |
|---|---|
| Drag the head | Moves the head (when **Drag moves the head** is ticked) |
| Drag anywhere else | Turns the view around the robot |
| Hold **Alt** and drag | Always turns the view, even over the head |
| Hold **Shift** and drag | Slides the view |
| Scroll wheel | Zooms |
| Double click | Resets the view |
| Arrow keys | Nudge the head 5 degrees (left and right turn it, up and down nod it) |
| **Reset view**, **Front**, **Side**, **Back (USB-C)**, **Top** | Jump to a standard view |
| Click a port or button when it glows | Plugs a cable in or out, or presses the robot's button |

The arrow keys do nothing while a text box or a slider has the keyboard. Click the 3D view first.

## On the robot's screen

| Do this | It does this |
|---|---|
| Click the screen | A tap |
| Drag across the screen | A swipe |
| **Open sheet**, **Close sheet**, **Next page**, **Back to face**, **Stop** (under Gestures) | The robot's own swipes, as buttons |

## In the side panel

| Do this | It does this |
|---|---|
| Type in **Something for the robot to say** and press **Enter** | Sends the words to the robot |
| Pick an **Area** and an **Action**, then **Do it** | Calls any tool by name |

On a phone or a touch screen, a finger works like the mouse: one finger drags, a pinch zooms.
